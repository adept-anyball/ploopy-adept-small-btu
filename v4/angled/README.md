# V4 - SLIM - ANGLED - 34mm trackball

It is essentially the same as the v4, so all the same instructions apply.

The differences are from this and the v4 slim flat version are:

- It has a 3 degree angle, so the front buttons are slightly higher
- The buttons are improved: more stable and less dead areas

> [!IMPORTANT]
> The STEP and STL files contain top, bottom and ball support for a 34mm ball.
> So, please remember to split the into objects before printing

I didn't have time to create a 38mm ball support yet, not sure if it will be done and not when.
For now, if you want to use a 38mm ball, you can use the 38mm trackball support from the v4 slim.
